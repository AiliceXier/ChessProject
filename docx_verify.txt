一、需求说明书（~1页）
1.1 项目背景
：国际象棋是广泛流行的策略游戏。本项目基于 Unity 引擎开发一款支持本地双人、人机对战、在线对战的多模式国际象棋平台，同时提供排行榜、棋谱记录、动画效果等扩展功能。
1.2 功能需求
• 
棋盘绘制与交互：3D 棋盘，鼠标点击选棋走棋
• 
走法校验：合法的国际象棋走法规则（吃子、王车易位、升变等）
• 
双人对战：本地黑白双方交替走棋
• 
人机对战：MinMax 搜索 + 评估表 / 云端 AI，4 级难度
• 
在线对战：房间创建/加入，实时同步
• 
棋谱记录与恢复：FEN/PGN 加载
• 
排行榜：分数记录与排名展示
1.3 性能需求
：AI 走棋响应时间（深度 3 平均 ≤5 秒），在线对战延迟 ≤500ms。
二、可行性分析（~1页）
• 
技术可行性：Unity 成熟、UGS Push 推送 + Cloud Code 架构经过验证可行
• 
使用可行性：仅需下载客户端，输入房间码即可联机
• 
经济可行性：Unity Personal 免费 + Unity Gaming Services 免费层 + 华为云 ECS 低配（1vCPUs / 2GiB / t6.medium.2）即可满足需求
三、软件设计说明（~4页）
3.1 概要设计
• 
客户端（Unity C#）：Player（主控）、UI（MainMenu/MoveHistory/Leaderboard 等）、AI 引擎
• 
服务端（C# Cloud Code）：HostGame/JoinGame/MakeMove/Resign 端点
• 
排行榜服务（Node.js + Express + better-sqlite3）：独立部署于华为云 ECS
• 
消息推送：UGS Push 实现实时同步
• 
聊天服务：WebSocket 服务器（Node.js + ws），同样部署于华为云 ECS
3.2 详细设计
核心数据结构
：FEN 字符串存储棋盘状态（例如 "rnbqkbnr/pppppppp/8/8/8/8/PPPPPPPP/RNBQKBNR w KQkq - 0 1"），ChessBoard 类封装走法生成、校验、局面评估。
关键接口
：
• 
ChessBoard
：LoadFromFEN、ToFEN、Moves、Move、IsCheckmate、IsStalemate、Resign
• 
ChessAI
：GetBestMove（接受 depth 参数，深度1~5）
• 
Player
：StartLocalGame、StartRobotGame、CreateGame、JoinLobbyByCode
• 
LeaderboardAPI
：SubmitScore、GetLeaderboard、GetPlayerRank、RenamePlayer
3.3 交互/界面设计
• 
3D 棋盘，鼠标点击选棋走棋，选中棋子高亮蓝色
• 
主菜单 → 游戏模式选择（本地/人机/AI难度选择/在线创建或加入）
• 
游戏内 UI：顶部回合信息、右下走棋历史面板、左下提示&amp;聊天、左侧评估条
• 
支持命令行输入走棋（坐标格式 e2e4 和代数记谱法 Nf3 均支持）
3.4 运行设计
• 
本地对战：单线程同步走棋
• 
人机对战：AI 走棋在后台 Task.Run 执行，不阻塞 UI 线程
• 
在线对战：客户端通过 Cloud Code 验证走法，通过 UGS Push 接收对手推送更新
• 
排行榜：异步 HTTP 请求，不影响游戏主线程

选择理由
：Unity 既有现成的 3D 国际象棋模型（Free Low Poly Chess Set），又有 Unity Gaming Services（Cloud Code + Lobby + Push）原生支持在线对战，学习曲线适中，社区资源丰富。Godot 虽然开源免费且包体小，但 3D 能力相对弱，且缺乏 UGS 这样的开箱即用云服务。Unreal 更适合大型 3A 项目，对课设来说过重。纯 C# 控制台能实现基本功能但缺少图形界面交互体验。
结论
：Unity 是平衡学习成本、资源丰富度和功能完整性的最佳选择。
